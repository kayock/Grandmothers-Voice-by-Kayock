# Famous Family Trees — Reference GEDCOM Collection

A user-supplied collection of example trees used to exercise the GEDCOM importer in **Grandmothers voice by Kayock**. This collection is **optional**; the application does not need it to run.

The trees include historical and royal families, US presidents, fictional character families, languages, organizations, and other relationship structures. Some are conceptual or fictional and are not verified genealogical research.

## How to use

Extract this ZIP somewhere on your computer. In Grandmothers voice by Kayock, choose a `.ged` file to import and explore it as you would any GEDCOM. Do not attempt to import this entire ZIP as a GEDCOM.

## Modifications to this copy

- 87 actual GEDCOM files are included, retaining the archive's original category folders and file names.
- The original `US presidents/GeorgeWashington+Family+Small.ged` was excluded because it contains a Google Groups HTML page rather than a GEDCOM.
- Submitter and repository contact fields (street addresses, phone numbers, email addresses and URLs) were stripped; email addresses appearing elsewhere were redacted. Genealogical person/family/event records were not intentionally changed.
- The original unfilled `MIT_License.txt` was *not* carried forward because it does not identify a copyright holder or grant verified rights for this data.
