# Grandmothers voice by Kayock — One Page Description

**Grandmothers voice by Kayock 2.1** is an offline Family Legacy Studio. It
converts GEDCOM genealogy files (5.5.1 and 7.0) into a standalone
interactive Family Story Explorer with an interactive family tree diagram,
timeline, places/migration view, photo and document galleries, and a
collaborative Tree Refinement Mode — plus Obsidian and Logseq Markdown
vaults, a printable Family Story Booklet, data diagnostics and
source-quality reports, and structured suggested-changes hand-offs for
genealogy software. Import a photo/document folder and the app reconnects
it to the media references in the GED, embedding images in self-contained
HTML or packaging an HTML+media ZIP for larger collections.

The tool is **read-only toward original GED files**: corrections, memories,
duplicate suspicions and merge suggestions are exported as reviewable
reports and versioned JSON backups with author attribution and timestamps —
never applied automatically. Stable tree identity (a content hash) keeps
family notes attached to the right file, with conflict review when backups
from relatives are merged.

It is 100% free and open source (MIT). No paid tiers, no ads, no accounts,
no telemetry, no cloud, no feature restrictions — fully functional offline
after extraction, opening by double-click in any modern browser with no
server or installation.

*Turn a family tree into a story you can walk through.*
